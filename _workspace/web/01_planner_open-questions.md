## 새로 생긴 항목(전환으로 발생 — 모두 안 막음)

### OQ-N1. 템플릿만(라이선스) 원하는 고객에게 파일을 어떻게 전달하나
- (a) 웹 구현은 안 막음. **2단계 관리자 설계를 막을 수 있음**(파일·납품 관리 기능 유무가 갈림).
- (b) 기본안: 문의(`template_custom`, scope=`license_only`) → 관리자 견적 답변 → 계약·입금(사이트 밖) → 담당자가 이메일로 파일 전달. 웹에는 다운로드 기능 없음. 문의 조회 결과에도 파일 링크 없음.
- (c) 선택지: ① 기본안(수동 전달) ② 관리자가 문의에 **1회용 다운로드 링크** 발급 → 문의 조회 화면에 링크 표시(계약에 `InquiryLookupResult.deliveries` 추가, SkinVersion 파일 필드 부활) ③ 라이선스만은 외부 마켓(크몽 등)으로 연결.

### OQ-N2. 법정 표기·정책 문서 범위
- (a) 안 막음.
- (b) 기본안: 온라인 결제가 없으므로 **환불정책 페이지 제거**, 푸터에서 통신판매업 신고번호 제외, 약관 3종(이용약관·개인정보처리방침·라이선스 정책). 제작 계약의 환불·해지 조건은 About Us 제작비용 섹션 유의사항 문구로 안내.
- (c) 선택지: 통신판매업 신고번호 표기 유지(이미 신고한 경우) / "제작 계약 약관" 페이지 추가 / 환불정책을 "계약 취소·환불 안내"로 유지.

### OQ-N3. About Us 콘텐츠·금액(구 OQ-C의 내용 부분)
- (a) 안 막음(시드 샘플).
- (b) 기본안: 제작 6단계·평균 3~6주, 요금제(템플릿 기본형/확장형/맞춤 제작/쇼핑몰 구축), 추가 옵션, 검색등록(1회 등록형/월 관리형, 순위 보장 없음), 유지보수(라이트/스탠다드/프로), 계약금/잔금 문구 — 모두 샘플 값·문구.
- (c) 운영자가 실제 금액·기간·계약 조건 제공. "검색등록"이 검색 광고 대행 의미인지 확인.

### OQ-N4. "인기순" 정렬 기준
- (a) 안 막음(서버 계산 필드 `Skin.popularityScore`로 추상화).
- (b) 기본안: 판매 수가 없으므로 상세 조회 수 + 템플릿 문의 수 + 데모 열람 수 가중합. mock은 시드 고정값.
- (c) 선택지: 관리자 수동 추천 순서 / 최신순을 기본 정렬로 변경하고 인기순 제거.

### OQ-N5. 기준가 공개 방식
- (a) 안 막음.
- (b) 기본안: 라이선스별 기준가를 카드("기준가 ○원부터")·상세에 공개 + "실제 비용은 요청 범위에 따라 견적" 캡션.
- (c) 선택지: 상세에서만 공개(카드는 숨김) / 전부 비공개("문의 시 안내") — 이 경우 목록 가격 필터·가격순 정렬 제거.

### OQ-N6. 비회원 개인정보 처리(문의·언어 요청 이메일)
- (a) 안 막음.
- (b) 기본안: 문의 — 목적 "문의 답변", 보관 3년(가정). 언어 요청 이메일 — 목적 "출시 알림", 출시 알림 발송 또는 요청 후 1년 경과 시 파기, 알림 메일에 수신 거부 링크(3단계). 두 폼 모두 [필수] 동의 체크박스.
- (c) 보관 기간·마케팅 활용 여부 운영자·법률 확인.

### OQ-N7. 문의 알림 메일과 조회 보안
- (a) 안 막음.
- (b) 기본안: 1단계 mock은 메일 미발송(성공 화면에서 접수번호 보관 강조). 3단계에서 접수 확인 메일(접수번호·조회 링크 `/contact/lookup?no=`) 발송. 조회는 접수번호+이메일 일치, 같은 접수번호 10분 내 5회 실패 시 429.
- (c) 선택지: 조회 페이지 없이 이메일 답변만(조회 라우트 제거) / 이메일 매직 링크(1회용 토큰)로 조회.
