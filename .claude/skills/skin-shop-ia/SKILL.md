# Skin Shop IA

## 산출물 3종
1. `01_planner_ia.md` — 사이트맵 트리 + **라우트 표**
2. `01_planner_spec.md` — 화면별 명세
3. `01_planner_open-questions.md` — 결정 필요 정책

### 라우트 표 형식 (QA가 링크 대조에 그대로 쓴다)
| 경로 | 페이지 | 레이아웃 | 접근 | 비고 |
|---|---|---|---|---|
| `/` | 메인 | web | 공개 | |
| `/skins` | 스킨 목록 | web | 공개 | `?category=&sort=&q=` 쿼리 |
| `/skins/:slug` | 스킨 상세 | web | 공개 | |
| `/admin/skins/:id/edit` | 스킨 수정 | admin | 관리자 | |

동적 세그먼트·쿼리 파라미터·리다이렉트 규칙(비로그인 → `/login?next=`)을 빠짐없이 적는다.

## 필수 페이지 체크리스트

### 사용자 웹 (1단계)
- 메인: 히어로(대표 스킨 쇼케이스), 신규/인기/카테고리 진입, 신뢰 요소(판매수·후기·업데이트 보장)
- 스킨 목록: 카테고리(쇼핑몰/기업/포트폴리오/랜딩 등 — 가정), 필터(플랫폼·기술스택·가격·반응형 여부), 정렬, 검색, 페이지네이션 또는 무한스크롤(Lenis와 궁합: 무한스크롤 시 `lenis.resize()` 필요 명시)
- 스킨 상세: 갤러리, **라이브 데모 링크/미리보기(PC·태블릿·모바일 토글)**, 라이선스 선택(가격 변동), 포함 파일·호환 환경·업데이트 로그, 후기, 문의, 관련 스킨, 장바구니/바로구매
- 장바구니 → 주문서(구매자 정보·약관 동의·결제수단) → 결제(mock) → 주문 완료
- 로그인/회원가입/비밀번호 찾기(소셜 로그인은 가정 표시)
- 마이페이지: 구매 내역, **다운로드(버전별)**, 라이선스 키/증서, 찜, 내 후기/문의, 회원정보
- 고객센터: 공지, FAQ, 1:1 문의 / 이용약관·개인정보처리방침·환불정책 / 404

### 관리자 (2단계)
- 관리자 로그인, 대시보드(매출·주문·신규회원·인기 스킨 추이)
- 스킨 관리: 목록/등록/수정(썸네일·갤러리·데모URL·배포파일 버전 업로드·가격·라이선스별 가격·카테고리·태그·노출상태)
- 카테고리/태그 관리, 주문·결제·환불 관리, 회원 관리(등급/정지), 리뷰·1:1문의 답변, 공지/FAQ, 메인 배너·기획전, 쿠폰/할인, 사이트 설정(약관 문구, 결제·메일 설정 자리)
- 관리자 권한 단계(최고관리자/운영자)는 open-question으로 확인

## 원칙
- 스킨 판매 특유의 흐름(데모 확인 → 라이선스 선택 → 구매 → 다운로드/업데이트)을 중심 사용자 흐름으로 적고, 일반 쇼핑몰 요소(배송 등)는 넣지 않는다 — 디지털 상품이라 배송·재고가 없다.
- 결제·환불·라이선스 정책은 법적/사업적 결정이라 추정값을 "가정"으로 표시하고 open-questions에 올린다.
- 각 화면의 데이터 항목은 `skin-data-contract` 스킬 형식의 엔티티명과 필드명으로 적어 계약 문서와 이름이 일치하게 한다.
